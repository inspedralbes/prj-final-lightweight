## Why

The E2E test suite using Playwright is already implemented, but the team lacks comprehensive documentation on how to work with it effectively. This leads to inconsistent practices, difficulty in debugging failures, and challenges in onboarding new developers. Creating this guide will standardize E2E testing workflows and improve development efficiency.

## What Changes

Create detailed documentation that explains:
- How to install dependencies and run E2E tests locally
- Naming and organization conventions for tests
- How to create new tests using Playwright fixtures, including the `twoUsers` pattern for multi-user flows
- Debugging techniques for local and CI environments
- Using Playwright Trace Viewer for analysis

The documentation will be placed in `docs/e2e.md` in the repository.
